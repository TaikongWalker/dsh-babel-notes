DSH 插件源

为 DeepSeek Harness 提供长篇中译工作流工具：项目脚手架、术语检查、LaTeX 元数据生成与进度查看。

添加索引

在 DSH 的“发现”页添加下面的索引 URL：

https://taikongwalker.github.io/dsh-babel-notes/index.json

安装插件

dsh plugin --profile default add dsh-babel-notes

或从 GitHub 安装：dsh plugin --profile default add github:TaikongWalker/dsh-babel-notes#9b7a0d86f1aefc5321c54c70bdd02c70c328565b

工具

  • translation_init从空白模板创建翻译项目。
  • translation_prepare生成 LaTeX 元信息、章序与术语表。
  • translation_check检查术语、标点、脚注数、未译英文与 TODO。
  • translation_term_candidates从原文提取术语候选。
  • translation_status读取项目元数据与进度表。

源码

github.com/TaikongWalker/dsh-babel-notes

插件只含工具链与空白模板，不包含任何原文、译文或扫描件。
