Open-source translation workflow · v0.1.0

把长篇翻译，做成一套可检查的工作流。

dsh-babel-notes 是一个开源翻译工作流插件：项目脚手架、术语检查、LaTeX 元数据、进度查看。它不替你翻译，它让翻译过程可追踪、可复核、可交付。

GitHub 仓库 npm 包 安装方式
Quick install / DSH
$ dsh plugin --profile default add dsh-babel-notes # 或在 DSH「发现」页添加市场索引 https://taikongwalker.github.io/dsh-babel-notes/index.json
MITDSH 0.2.xPython 3.10+
01

五个工具

插件把翻译流程拆成五个可调用的动作。每个动作都对应仓库里的一个 Python 脚本或一份模板，DSH 负责调度，你负责判断。

01

translation_init

从空白模板创建翻译项目：project.json、chapters、notes、glossary、generated。

02

translation_prepare

从项目元数据生成 LaTeX 元信息、章序与术语对照表。

03

translation_check

检查术语残留、禁用变体、中文标点、脚注/图数量、未译英文与 TODO。

04

translation_term_candidates

从 source/ 提取术语候选，写入 candidates.csv，供人工定名。

05

translation_status

读取 project.json 与 progress.csv，返回项目当前进度。

02

在哪里能用

插件本身基于 DeepSeek Harness 的 Cordis 工具 API。工作流里的 Python 脚本和 LaTeX 模板是通用的，所以 Claude Code、Codex 也能手动使用，只是不能“一键安装”。

环境直接安装使用方式
DeepSeek Harness可以npm 包名、GitHub 仓库或市场索引；安装后 5 个工具直接可用。
Claude Code不能clone 仓库，手动使用 scripts/ 与 template/；可读写文件、执行 Python 与 LaTeX。
Codex不能在终端调用同一套 Python 脚本，复制 template/ 作为项目骨架。
03

快速开始

DSH

直接安装

安装后新开会话，直接让 Agent 调用 translation_init。

dsh plugin --profile default add dsh-babel-notes
Claude Code

手动使用

把仓库当工具库，脚本和模板可直接在项目里跑。

git clone https://github.com/TaikongWalker/dsh-babel-notes.git
python scripts/prepare.py --project .
python scripts/check.py --project . --summary
Codex

终端调用

复制 template/ 建项目，然后用 Codex 执行脚本。

cp -r template my-book
python scripts/check.py --project my-book --summary
04

项目结构

插件自带一个可直接编译的中文书籍骨架；原文、译文与 PDF 由使用者自己放入，插件不附带任何版权文本。

translation-project/ ├─ project.json # 书目元数据 ├─ main.tex # XeLaTeX 总装入口 ├─ preamble.tex # 版式与宏 ├─ chapters/ # chNN.tex，一章一个文件 ├─ frontmatter/ # 封面、版权页、译者说明 ├─ backmatter/ # 术语表、译后记 ├─ glossary/terms.csv # 术语表（唯一权威） ├─ notes/ # 背景、风格、决策、进度 ├─ source/ # 原文档案（只读） ├─ figures/ # 图片 ├─ generated/ # 脚本生成，勿手改 └─ dist/ # 最终 PDF
05

边界与依赖

不是翻译引擎

它不替你翻译，也不判断译得好不好。它把“项目管理、术语、检查、排版”这一套流程工具化，判断仍然由译者做。

不附带版权内容

仓库里没有原文、译文或 PDF，只有脚本、空白模板和说明。MIT 许可；使用者放入项目的文本，其版权由使用者负责。

PDF 依赖

模板使用 XeLaTeX + ctexbook；超长脚注跨页依赖 bigfoot 与 ncctools。Python 脚本只用标准库。

DSH 版本

插件声明 engines.dsh: >=0.2.0 <0.3.0。若你的 DSH 是 0.3 以上，先确认兼容性再安装。
